# Mandarin Maverick · Arbeitsblätter

Arbeitsblätter im Design von Mandarin Maverick (Hanzi #B02418 in Kaiti, Pinyin #2271FF, Deutsch #111111, Struktur Türkis #039A9A).
Die Schülerfassungen laufen offline im Browser (Hanzi-Schrift als Teilmenge eingebettet), werden ausgefüllt, als PDF gespeichert und in Moodle abgegeben.

- Übersicht: https://smartuptake.github.io/mandarin-maverick-arbeitsblaetter/
- Generator (Offline-Fassung, speichert im Browser): https://smartuptake.github.io/mandarin-maverick-arbeitsblaetter/generator/ – die Fassung mit gemeinsamer Sammlung und Claude-Vorschlägen liegt auf claude.ai
- Die Blätter (JSON mit Lösungen) liegen nicht öffentlich, sondern in der Werkstatt bzw. im Generator.
- Bauen (Werkstatt `~/Documents/MM-Werkstatt/fs-arbeitsblatt-generator`): `node tools/build.mjs ~/GitHub/mandarin-maverick-arbeitsblaetter/docs --fach=mm`
- Schrift: siehe assets/fonts/LXGW-WenKai-LIZENZ.txt
